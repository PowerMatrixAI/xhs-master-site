# 精选vlog视频开发需求文档

## 1. 目标与范围

在「视频方案」中新增「精选vlog视频」，替代「图片生成视频」，与「直接使用视频」「创意故事视频」并列。

首期只覆盖民宿场景：从游客视角呈现抵达、入住、房间体验和特色活动等环节，形成有氛围、有节奏的短视频。成片不使用旁白，由一首平台配乐贯穿整片。

管理员事先研究同行优秀视频、纪录片和 Vlog，将可借鉴的镜头组织、节奏与视觉语言沉淀为模板。生成时不实时搜索视频，也不复制参考作品的具体画面或音乐。

## 2. 产品流程

```text
选择精选vlog模板并填写可选要求
→ AI 结合民宿资料生成脚本
→ 用户检查并确认脚本
→ 通过现有接口新增本周视频笔记，脚本暂留在当前页面会话
→ AI 规划首帧、视频动态和转场
→ 控制台 BFF 调用后端 AI，从平台配乐库候选中选择一首配乐
→ 生成完整智能体任务
→ 智能体准备首帧，人工验收
→ 生成并拼接视频片段，铺设整片配乐
→ 输出成片，供后续笔记草稿流程使用
```

每条脚本包含 3–6 个镜头，每段约 5 秒。模板规定必要体验环节，具体镜头结合当前民宿的真实资料调整。

模板可采用主观镜头，也可按需要安排虚构游客角色或第一人称故事；不得将虚构经历表述为真实顾客证言。房型、设施、服务、价格等可核验信息不得编造。

切换模板或修改补充要求后，未确认脚本失效。生成完整任务后，镜头方案与所选配乐保存在笔记任务指令中，后续模板修改不改变已生成的任务。

## 3. 平台模板

新增独立的「精选vlog模板」资源。管理员可以创建、编辑；普通登录用户可以查询和使用。它与现有强制绑定主角形象的创意故事模板分开存储，但可以复用管理界面和生成流程中的通用组件。

模板至少包含：

| 字段 | 说明 |
| --- | --- |
| `id`、`name` | 模板标识和展示名称 |
| `outline` | 整体体验主线 |
| `beats` | 预设体验环节、镜头职责和节奏要求 |
| `requiredScenes` | 必须保留的环节或事实边界 |
| `perspectiveGuidance` | 主观镜头、游客入镜及叙事视角要求 |
| `visualGuidance` | 摄影质感、光线、构图和转场方向 |
| `musicTags` | 建议的配乐情绪与节奏标签 |

首期至少配置一套适用于民宿的模板，涵盖抵达、入住、空间体验、特色体验和结束场景。模板环节可以合并为镜头，最终仍须符合 3–6 镜头的限制。

## 4. 平台配乐库

在现有「平台素材库」增加配乐管理区。配乐是平台共享资源，不归属单个客户账号。

每条配乐至少保存 `id`、名称、标签、时长、文件格式、对象存储路径、长期有效的 HTTPS 下载地址、授权状态和创建时间。管理员可以上传配乐、查看曲目、修改标签与授权状态。普通用户不查看配乐列表，也不手动选择配乐；生成完整任务时由控制台 BFF 调用后端通用 AI 自动选曲。

服务端必须检查上传权限、实际音频格式、可解码性及存储结果。每次上传创建独立文件对象，不覆盖已被历史任务引用的文件。仅授权状态为可用的曲目参与选曲。

## 5. 脚本生成与确认

AI 读取服务端权威模板、账号资料、知识库中的民宿事实和用户补充要求，输出结构化脚本，包括：

- 标题、概要、叙事视角、整片情绪和配乐氛围标签；
- 每个镜头的顺序、体验环节、画面事件、镜头职责、建议素材及游客是否入镜；
- 新增周计划视频笔记所需的主题、目标与素材要求。

控制台校验镜头数量、顺序和必填字段。用户确认后，通过现有周计划接口新增一篇独立的本周视频笔记；完整脚本暂留在当前页面会话。若此时刷新且尚未生成完整任务，需要重新生成脚本。完整任务生成后，其镜头方案与配乐链接写入现有笔记任务的 `plan`。

## 6. 完整视频任务

确认脚本后分阶段生成：

1. 根据镜头职责与账号素材库的图片元数据，选择真实素材或规划 AI 补图。
2. 规划各段约 5 秒的视频动态和相邻镜头转场，不生成旁白文本，不调用 TTS。
3. 控制台 BFF 从业务服务端获取可用配乐候选，根据已确认脚本的场景、节奏和情绪，将候选曲目的 ID、名称与标签交给现有后端 AI；AI 只返回候选曲目 ID。
4. BFF 核对该 ID 属于本次候选集，再从候选记录取出曲目名称与原音频 HTTPS 地址，写入执行任务。

AI 不得编造配乐 URL。配乐库为空、没有有效选择或链接不可用时，提示补充配乐，并停止生成完整任务。

首帧继续采用素材库优先、缺少合适素材时使用 AI 补图的策略。真实素材与 AI 补图混用时，沿用现有风格锚点规则；真实场地图片不因统一风格而大幅重绘。

完整智能体指令保存在现有笔记任务的 `plan` 中。

## 7. 智能体执行

`xiaohongshu_auto_op` 增加独立的精选vlog执行计划类型，复用「准备首帧 → 人工验收 → 渲染」与断点续跑流程。现有创意故事视频旁白计划保持兼容。

执行步骤：

1. 下载所需图片及选定配乐到智能体本机。
2. 制作或精修各镜头首帧，等待人工验收。
3. 静音生成每段视频并按顺序拼接。
4. 将同一首配乐铺满整片：不足时循环，超长时裁切，首尾做短淡入淡出。
5. 校验最终视频时长、画幅和单条有效音轨。

音频下载或处理失败时停止，并保留已完成的首帧与视频片段供重试。任务不得依赖控制台服务器上的本地素材路径。

## 8. 接口与兼容性

服务端新增以下能力：

- 精选vlog模板的管理员创建、编辑接口及登录用户列表接口；
- 平台配乐的管理员上传、标签与授权状态维护接口；
- 供控制台 BFF 读取可用配乐候选的接口；AI 选曲沿用现有 `/ai/v1/complete`，不新增业务服务端选曲接口。
- 不新增脚本关联表或专用确认接口；沿用现有周计划和笔记任务接口。

控制台增加独立的脚本与执行计划类型。已生成的「图片生成视频」历史任务及指令继续可用，不回溯转换；「直接使用视频」和「创意故事视频」流程不变。

## 9. 验收标准

- 同一模板用于不同民宿时，体验流程成立，画面能体现各自可核验的特点。
- 确认脚本后新增独立周计划视频笔记；完整任务生成后，刷新仍可查看已保存的执行指令。
- 真实素材、AI 补图及混合镜头都可制作首帧，混合镜头保持合理的视觉连续性。
- 控制台 BFF 只接受后端 AI 返回的可用候选曲目 ID；无有效配乐时给出明确错误，不生成虚构链接。
- 成片不含旁白，配乐覆盖完整视频，最终只有一条音轨。
- 原有直接视频、创意故事视频及历史图片转视频任务通过回归测试。

## 10. 实施顺序

先完成服务端模板、配乐及自动选曲能力；再接入控制台「精选vlog视频」的脚本确认与任务生成流程；最后扩展 `xiaohongshu_auto_op` 的无旁白配乐执行链路。

联调使用一组真实民宿资料、图片素材和至少两首不同标签的已授权配乐，验证脚本适配、配乐选择及最终成片。
