# 精选vlog视频：服务端开发需求文档

## 1. 开发目标与范围

为「精选vlog视频」首期民宿场景提供以下服务端能力：

1. 平台共享的精选vlog模板管理与查询。
2. 平台共享配乐的上传、元数据管理与查询。
3. 向控制台的 Next.js BFF 提供当前可用配乐的候选元数据和长期下载地址，由 BFF 调用现有后端 AI 服务完成自动选曲。

本服务不生成首帧、视频片段或成片，也不执行配乐剪辑。上述制作步骤由控制台生成任务、`xiaohongshu_auto_op` 执行。首期不实时抓取或分析同行视频；管理员将研究结论人工写入模板。

以下路径和字段为与控制台联调的建议契约；实现时可依照服务端路由规范调整命名，但请求语义、响应字段和权限边界必须一致。全部接口位于现有 `/client` 下，使用当前登录签名鉴权及项目统一的 `status`、`message`、`code`、`data` 响应结构。

## 2. 数据模型

### 2.1 平台模板 `featured_vlog_templates`

| 字段 | 说明 |
| --- | --- |
| `id` | 服务端生成的模板 ID，不与创意故事角色模板 ID 混用 |
| `name` | 展示名称 |
| `outline` | 整体体验主线 |
| `beats` | 有序环节数组；每项包含环节名称、镜头职责、视觉/节奏引导和是否必需 |
| `required_scenes` | 必须保留的体验环节和事实边界 |
| `perspective_guidance` | 主观镜头、游客入镜或第一人称表达规则 |
| `visual_guidance` | 摄影质感、光线、构图和转场方向 |
| `music_tags` | 推荐的配乐情绪与节奏标签 |
| `version` | 从 1 递增；每次编辑增加，供管理员并发编辑校验 |
| `created_by`、`created_at`、`updated_at` | 管理员及审计时间 |

首期模板按平台共享，不绑定业务账号或具体房源。创建时要求名称、主线及至少一个编排环节；文本和数组必须设置合理长度上限，避免超长模板进入 AI 上下文。模板列表使用稳定顺序返回。至少由管理员配置一套民宿模板后，用户才可选择此模式。

### 2.2 平台配乐 `platform_music`

| 字段 | 说明 |
| --- | --- |
| `id`、`name` | 服务端生成 ID 与曲目名称 |
| `tags` | 有序去重后的情绪、节奏、场景等标签 |
| `duration_seconds`、`mime_type`、`size_bytes` | 服务端解析的音频属性 |
| `file_path` | 对象存储内部路径，不作为公开字段返回 |
| `audio_url` | 无需控制台登录、可供外部智能体长期下载的 HTTPS 原音频地址 |
| `authorization_state` | `available` 或 `unavailable`；只有 `available` 参与选曲 |
| `authorization_note` | 管理员记录曲目的业务使用授权依据或范围 |
| `created_by`、`created_at`、`updated_at` | 上传管理员及审计时间 |

每次上传写入独立对象，不按文件名或曲目名称覆盖已有文件。本期不提供物理删除接口；下架只更新状态，已经生成的任务仍可继续引用原文件。

## 3. 平台模板接口

| 接口 | 权限 | 请求要点 | 响应要点 |
| --- | --- | --- | --- |
| `POST /client/featuredVlog/v1/template/list` | 登录用户 | 空 JSON | `{ templates: [...] }`，无模板返回空数组 |
| `POST /client/featuredVlog/v1/template/create` | 平台管理员 | 模板全部编辑字段 | 返回新模板及 `version: 1` |
| `POST /client/featuredVlog/v1/template/update` | 平台管理员 | `templateId`、当前 `version`、编辑字段 | 乐观锁校验版本，成功后返回新版本 |

服务端管理员权限判断必须使用登录用户的真实角色，不接受客户端传入的 `isAdmin`。模板更新版本冲突时返回明确错误，避免覆盖管理员并发编辑。普通用户不能修改模板。

列表响应中的 `beats`、`requiredScenes`、`musicTags` 应为数组，字段使用 camelCase，与控制台其他平台模板接口保持一致。客户端生成脚本时只传模板 ID；用于 AI 的权威模板内容由 Next.js BFF 重新查询，不信任浏览器提供的模板文本。

## 4. 平台配乐接口

| 接口 | 权限 | 请求要点 | 响应要点 |
| --- | --- | --- | --- |
| `POST /client/featuredVlog/v1/music/upload` | 平台管理员 | `multipart/form-data`：`name`、`tags`、`authorizationNote`、`file` | 返回新配乐记录 |
| `POST /client/featuredVlog/v1/music/list` | 平台管理员 | 空 JSON；可按状态筛选 | 返回供管理员管理的曲目列表 |
| `POST /client/featuredVlog/v1/music/update` | 平台管理员 | `musicId`、名称、标签、授权说明与状态 | 返回更新后的曲目；不替换音频对象 |
| `POST /client/featuredVlog/v1/music/candidates` | 有权访问账号的登录用户，经 Next.js BFF 调用 | `accountId` | 返回所有 `available` 曲目的候选元数据和下载地址；不执行 AI 选曲 |

上传支持 MP3、M4A 和 WAV；服务端同时校验 MIME、文件头、可解码性、正数时长及配置的文件大小上限。不可只信任扩展名或客户端传来的时长。对象存储采用独立随机路径，例如 `platform-music/<yyyy>/<MM>/<uuid>.<ext>`。上传失败不得生成可查询的配乐记录；对象上传成功而数据库写入失败时应清理孤立对象。

新上传曲目默认 `unavailable`，管理员填写授权依据并明确启用后才可选曲。`audioUrl` 不得使用需要登录的接口或会在任务执行前过期的短期签名链接。只向客户端返回下载所需的 HTTPS 地址，不暴露存储密钥。

## 5. 视频脚本与现有笔记接口的边界

本期不新增 `featured_vlog_scripts` 表，也不新增脚本确认或详情接口。沿用创意故事视频的现有做法：用户确认脚本后，控制台从脚本提取笔记主题、目标与素材要求，通过现有周计划/笔记保存接口新增一篇 `video_text` 笔记；脚本本身暂留在当前页面会话。完整视频任务生成后，控制台将包含镜头计划、选定配乐资料和执行指令的内容写入现有 `noteTask.plan`。

因此，确认笔记后若尚未生成完整任务就刷新页面，完整脚本无法从服务端恢复；用户需要重新生成脚本。此限制与当前创意故事视频一致，控制台应清楚提示。服务端不应为本期另建脚本表或改变现有周计划、笔记任务结构。

## 6. 自动选曲的数据契约

选曲方式与现有「图片方案 → AI 自动选图」一致：Next.js BFF 通过 `music/candidates` 读取候选配乐，再调用现有 `/ai/v1/complete`，将已确认脚本的体验环节、整体情绪、节奏和音乐氛围标签，与候选配乐的 ID、名称、标签及必要音频属性一起交给文本 AI。AI 只返回候选中的一个 `musicId`，或明确表示无合适曲目；BFF 校验 ID 确实属于本次候选集，并从候选记录取得真实下载地址。音频 URL 不交给 AI 生成。

业务服务端只负责查询与权限：`music/candidates` 验证登录用户有权访问 `accountId`，仅返回 `authorizationState=available` 且具有有效 HTTPS 地址的曲目。普通用户的控制台页面不展示候选列表；该接口供服务端运行的 BFF 使用。服务端不接收脚本、不调用 AI，也不保存选曲结果。

控制台将选中的配乐 ID、名称和地址写入最终任务并保存到 `noteTask.plan`。若候选集为空、AI 没有选出合适曲目、返回无效 ID 或调用失败，BFF 明确报错；不随机兜底，也不生成无配乐任务。

候选列表响应示例：

```json
{
  "status": true,
  "message": "",
  "code": "",
  "data": {
    "music": [
      {
        "id": 28,
        "name": "山间清晨",
        "tags": ["清晨", "轻快", "自然"],
        "durationSeconds": 42.5,
        "audioUrl": "https://cdn.example.com/platform-music/2026/09/uuid.mp3"
      }
    ]
  }
}
```

候选曲目下架后不再出现在新请求中，但原音频不能因下架立即删除，以免破坏已生成任务。重复生成完整任务可能重新选曲；已保存的历史任务保持原有曲目引用。

## 7. 权限、错误与日志

- 模板写接口、配乐上传、维护和列表接口仅平台管理员可用；普通用户只可查询平台模板。
- 候选接口需校验用户与业务账号的归属关系；普通用户不在控制台查看配乐列表或手动选曲。
- 候选响应不暴露内部对象路径或存储凭据；BFF 调用 AI 时只传曲目 ID 和文字元数据，不传账号鉴权信息或音频 URL。
- 日志记录请求 ID、用户 ID、账号 ID、笔记 ID、模板 ID、候选配乐 ID 和选中 ID；不得记录 token、存储密钥或完整音频文件内容。
- 配乐授权状态由管理员控制，AI 只能从服务端筛出的可用集合中选择。

至少区分未登录（401）、无管理或账号权限（403）、参数无效（400）、模板编辑版本冲突（409）、存储失败（5xx）。无可用或无合适配乐、AI 调用失败等选曲错误由 BFF 处理。所有失败均使用项目统一响应结构和清晰的中文 `message`；不得生成看似成功的曲目记录。

## 8. 与现有系统的边界

- 不改动创意故事角色库和角色模板接口；精选vlog模板不要求 `characterId`。
- 不修改现有周计划和笔记任务字段，也不新增服务端脚本存储；执行任务仍写入既有 `noteTask.plan`。
- 不让账号级素材库的图片、视频上传接口直接承担平台音频上传。现有 COS 能力可在服务端内部复用，但必须增加音频类型的校验、存储和长期下载能力。
- 业务服务端提供权威模板及配乐候选库；脚本生成、首帧规划、调用后端通用 AI 选曲和任务组装由控制台 BFF 负责，视频制作与音频铺设由外部智能体负责。

## 9. 服务端验收

1. 管理员可创建和编辑模板；普通用户可以列表查询，不能修改。
2. 不同账号可查询同一平台模板；普通用户不能调用配乐列表、上传或维护接口。
3. 管理员可上传并启用合法音频；伪装格式、损坏文件、无授权状态曲目不能参与选曲。
4. 候选接口会拒绝无权访问的账号；只返回可用曲目的服务器记录，不接受客户端提交候选曲目。
5. 控制台 BFF 调用后端 AI 后，只接受候选列表中存在的曲目 ID；虚构 ID、空结果或 AI 服务错误均明确失败。
6. 配乐下载地址在不携带控制台登录头的外部环境中可访问；下架不破坏历史任务链接。
